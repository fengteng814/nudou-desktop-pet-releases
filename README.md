本版增加拖到屏幕外露左右边缘后松手自动收边、大头头像图标、每台电脑每日及手动更新检查。默认更新来源为本公开仓库，无需账号、令牌或 GitHub CLI；已有手动配置优先。

下载完整 ZIP 并解压，双击 `安装或更新.cmd`。核对版本、目录与校验值后点击确认；默认取消。更新前正常关闭目标目录旧版、备份程序及配置，保留配置与笔记。安装后手动启动。`回滚上一版.cmd` 只恢复程序文件，保留用户数据。

更新入口：桌宠右键 → 设置 → 检查更新。新版只提示，手动下载并确认安装，不静默替换。每台电脑每天检查一次，未运行时下次启动补查，手动检查可随时进行。

本仓库只含已授权安装包、说明、校验与更新清单；源码保留在私仓。EXE 内含努豆人物、头像和动画及现有美术音频，音频来源与许可随包提供。没有个人配置、配对凭据、笔记、运行队列、日志或测试材料。
