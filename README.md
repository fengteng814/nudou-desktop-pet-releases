安装包需要 Windows .NET Framework 4.8；按照安装器提示确认安装或更新。已有桌宠也可以右键 → 设置 → 检查更新。

## 这次更新

- 在桌宠内输入配对码即可连接已授权的任务服务，无需手动编辑配置。
- 管理清单优先显示本地缓存，后台自动重连；离线提示在鼠标悬停时显示。
- 编辑待办时可以转移所属清单，保留任务编号和完成状态。
- 修复檐下听雨抬臂时的肩部衣料缺块。
