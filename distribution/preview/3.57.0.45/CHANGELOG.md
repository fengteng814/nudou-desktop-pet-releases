# 努豆桌宠 3.57.0.45 Preview

- “立即更新”在桌宠内下载并验证安装包，自动备份、更新和重启。详情中保留离线安装包选择。
- 下载过程中显示进度，关闭窗口可取消；中断或校验失败不修改安装目录，可重试。安装启动结果不明时不会重复启动。Windows 安全提示保留。
- 自动更新只允许更新原目录中已经登记的较旧版本，保留设置、配对、任务记录与回退备份。
- ToDo 完成操作本地保存后播放勾选、渐隐和上移动画，后台继续同步。真正需要核对的记录显示橙色提示，可点击直接处理。
- 包含新增待办弹窗排版、玻璃控件协调、清单选择样式、弹窗进入和新增条目动画，以及折叠标签拖动、边栏高度调整等改进。

## 首次升级

3.57.0.44 及以前版本尚无内置下载功能，第一次请下载并运行本版 setup.exe，选择原安装目录。升级到本版以后，点击“立即更新”即可完成后续更新，无需跳到下载页。

安装器正常退出应用，备份并保留用户数据。另提供纯解压 ZIP。NAS / Vikunja 沿用现有配对和账号权限。程序包不含账号、配置、任务数据或源码。SHA256 见同目录校验文件。程序及安装器尚未代码签名，请遵循 Windows 安全提示。
