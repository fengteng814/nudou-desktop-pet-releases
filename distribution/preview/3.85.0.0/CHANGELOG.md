# 努豆桌宠 3.85.0.0 Preview

## 新增与改进

- 标题栏增加新建便签「+」；已有文字先安全收好，再开始下一条。
- 便签展开与折叠统一文字位置和字号，首条与其他便签保持相同尺寸规则，缩小正文右侧留白。
- 拖动时完整便签随鼠标移动，保留原位置提示；继续支持排序和拖出独立窗口。
- 颜色入口与选择改为矩形纸片色块，选中颜色使用边框区分。
- Obsidian 选库区域精简为仓库选择与浏览，路径放入提示，异常时才显示说明。
