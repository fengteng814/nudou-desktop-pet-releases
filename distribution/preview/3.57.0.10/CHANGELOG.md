# 努豆桌宠 3.57.0.10 Preview

- 修复原生安装器对旧备份目录和事务锁的所有者兼容问题，避免正常升级要求用户手动执行权限修复命令。
- 安装前验证目标及备份边界，保留原有配置、身份、任务数据和回退备份。
- 保留 3.57.0.9 的家庭待办 / Vikunja 可折叠桌面侧栏、简洁家庭留言、闪烁修复和简化更新界面。

待办入口：右键桌宠 → 动作与娱乐 → 日常待办。侧栏中可完成/恢复任务，新增和编辑通过“打开清单”；Vikunja 需要已有授权，任务状态以来源确认结果为准。

3.57.0.8 / 3.57.0.9 原生客户端可通过“检查更新”安装。旧 .5/.6/.7 需手动运行本版 setup.exe，在原安装目录完成一次迁移。已遇到备份所有权报错的用户，请直接运行本版安装器，并选择原安装目录。

提供原生 setup.exe 和纯解压运行 ZIP；SHA256 见同目录 SHA256SUMS.txt。程序及安装器尚未代码签名，请遵循 Windows 安全提示。

具体的构建、权限兼容及安装回退验证结果以本版发布记录为准；真实任务操作及物理多屏切换仍需实际使用验证。程序包不含个人配置、任务数据、凭据或源码。
