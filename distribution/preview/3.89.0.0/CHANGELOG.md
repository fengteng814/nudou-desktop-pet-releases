# 努豆桌宠 3.89.0.0 Preview

## 新增与改进

- 快记主窗口和独立便签统一采用展开、收起动画：打开约 220ms，关闭约 140ms，窗口位置和尺寸保持不变。
- 原生窗口先在遮蔽状态完成配色、布局和首帧绘制，玻璃底板在首次显示前同步裁剪区域，继续处理出现前的小白块。
- 动画沿用便签与桌宠统一的视觉策略；玻璃效果、颜色、圆角保持一致，系统关闭菜单动画或启用高对比度时直接显示与关闭。
- 保存成功后才开始关闭动画；保存失败、取消关闭或再次呼出时保留完整可编辑窗口。关闭桌宠和便签管理操作仍同步完成保存与关闭。
- 保留快记与每张独立便签的位置、大小记忆、标题栏高度实时预览以及原生中文输入状态。

## 验证与使用

本轮最终构建通过 229 项应用自动检查和 21 项原生安装器检查，共 250 项；另有 4 项实际界面检查通过。覆盖快记与独立便签的首帧遮蔽、玻璃底板首次显示前裁剪、首个可见区域中的编辑器表面准备、展开与收起、保存失败、取消与再次呼出、几何记忆、标题栏实时预览和输入状态。实际操作分别打开并关闭两种窗口，原生日志记录到中间裁剪状态且窗口尺寸固定；这些日志不是高速合成屏幕视频。

通过圆盘打开快记，或从快记拖出独立便签，即可使用统一开关效果。
