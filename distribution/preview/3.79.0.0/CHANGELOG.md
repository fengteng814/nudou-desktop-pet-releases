# 努豆桌宠 3.79.0.0 Preview

## 新增与改进

- 快记与多条固定便签融合在同一窗口。圆盘打开即输入；记录默认折叠，显示首行摘要，点击原地展开阅读或编辑。
- 窗口置顶独立控制，Ctrl＋滚轮调整并记住字号。正文即时显示，不使用打字机效果。
- 支持常用 Markdown：标题、粗体、斜体、列表、引用、代码、表格和链接；笔记内待办框可直接勾选并回写原文，不创建 NAS 待办。
- 支持粘贴图片及截图，本地保存附件；导出 Markdown 时一并带走图片。
- 草稿在后台按顺序保存，关闭前刷新最后修改；保存失败保留文字并阻止关闭。支持连续记、历史搜索、原地编辑、软删除及回收站恢复。
- 提供纸条配色、记录表情、主动捞一条灵感、今日纸叠与可关闭的陪写状态；记下后给予简短收好反馈。
- 历史分批显示，搜索覆盖所有记录；旧快记格式、记录标识、项目关联及灵感罐快照继续保留。

## 验证与使用

40 项存储/图片检查、44 项 Markdown/输入检查、47 项集成检查、27 项界面回归及 21 项安装器事务检查通过。已检查实际原生窗口截图；尚未由真人完成日常使用验收。

从圆盘或右键菜单进入快记。Ctrl+Enter 记下；未置顶时保存后收起，窗口置顶时留在窗口继续写。Esc 或关闭保留当前草稿。每条最多 4000 个字符，图片以本地附件引用保存。

关闭前会确保写入完成；强制终止或突然断电发生在“保存中”时，尚未落盘的最后修改不保证恢复。快记及图片保存在本机，迁移或备份请一起保留 nudou-quick-*.ini 与 quick-note-assets 文件夹。安装更新由客户端原有确认流程完成。
