# 努豆桌宠 3.57.0.56 Preview

本次包含 3.57.0.52–3.57.0.56 的累计修复。

- 修复通透度从 0 到 1 突然全透明，改为连续变化，文字保持清晰。
- 待办条目按实际内容计算高度，取消空行预留；条目间距设为 0 时更紧凑。
- 模糊为 0 时清晰显示背景，低值逐步增加模糊；增强滑杆上半段，100 时背景明显更模糊，0–50 的细调保持不变。
- 修复拖动通透度时其他滑杆区域闪烁，保留实时预览、保存和取消行为。
- 兼容原始请求回执查询，增加任务服务初始化及刷新失败后的自动恢复与脱敏诊断，减少同步阻塞。

更新保留原有任务、设置及配对信息。玻璃效果已通过实际桌面对比；不同背景、缩放及显卡上的观感可能有所不同。
本次沿用已安装验证的同一构建。VERSION.json 中的 local-preview / not-published 是构建时状态，当前发布状态以在线更新清单为准。
