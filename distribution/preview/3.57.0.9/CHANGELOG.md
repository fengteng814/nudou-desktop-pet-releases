# 努豆桌宠 3.57.0.9 Preview

- 新增可固定、可折叠的桌面待办侧栏，支持家庭待办与 Vikunja 切换、左右停靠、宽度调整和可选置顶，并记住显示状态。
- 简化家庭留言界面，修复留言列表及正文反复刷新引起的闪烁。
- 简化桌宠内的更新窗口及原生安装器，详细信息按需展开。

入口：右键桌宠 → 动作与娱乐 → 日常待办。侧栏中可完成/恢复任务，新增和编辑通过“打开清单”；Vikunja 需要已有授权，任务状态以来源确认结果为准。

3.57.0.8 原生客户端可通过“检查更新”安装。旧 .5/.6/.7 需手动运行本版 setup.exe，在原安装目录完成一次迁移。原生安装保留配置、身份和任务数据，并创建回退备份。

提供原生 setup.exe 和纯解压运行 ZIP；SHA256 见同目录 SHA256SUMS.txt。程序及安装器尚未代码签名，请遵循 Windows 安全提示。

已完成隔离的侧栏、更新界面和安装回退验证；真实任务操作及物理多屏切换仍需实际使用验证。程序包不含个人配置、任务数据、凭据或源码。
