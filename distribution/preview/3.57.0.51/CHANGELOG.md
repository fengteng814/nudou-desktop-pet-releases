# 努豆桌宠 3.57.0.51 Preview

本次包含 3.57.0.47–3.57.0.51 的累计更新。

- ToDo 支持右键删除及 Delete 快捷键；确认后同步删除，删除重复任务会停止后续生成。
- 未完成待办支持同一清单内拖动排序，顺序同步至 NAS 和墨水屏当天待办。
- 修复右键菜单对齐、旧同步警告和提示遮挡；增加“显示所属清单”设置。
- 自动核对丢失回执：确认请求未执行且过期后解除阻塞，让后续任务继续同步；未提交的新建内容保留。权限异常或执行结果不明仍提示核对。
- 玻璃模糊改为连续滑杆，拖动实时预览；HSL 调色预存雾蓝、松绿、暖砂、暮紫、玫瑰、石墨。取消恢复原设置。
- 收放动画提前准备玻璃背景，避免先纯色后玻璃。
- 窗口显示前先加载本地缓存，再后台连接服务器；等待连接或离线时保留待办内容。

已配对设备保留原有任务、设置及配对。排序与同步恢复功能需要配套的 NAS 任务服务。
本次发布沿用已安装验证的同一构建；VERSION.json 中的 local-preview / not-published 是构建时状态，当前发布状态以在线更新清单为准。
