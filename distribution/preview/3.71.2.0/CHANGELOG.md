# 努豆桌宠 3.71.2.0 Preview

相对上次公开版本 3.71.1.0 的更新。完整保留 3.71.1、3.71 和 3.70.1 的改动。

## 新增与改进

- 管理清单中的上移、下移仅调整本机显示顺序，不上传服务器，也不进入同步队列。
- 点击后立即保存并应用到 Todo 侧栏，无需等待服务器响应或点击保存。
- 离线、后台同步中、清单显示选择正在保存时，都可调整本机顺序。
- 重启后保留顺序，服务器返回旧顺序不会覆盖本机设置；不同配对身份分别保存。

## 使用范围与验证

清单的显示勾选继续按现有服务器流程保存；重命名和删除仍保留原有权限及同步校验。

已通过 82 项后台清单与本地排序回归、48 项离线清单回归、应用自检和 21 项隔离安装器检查。本机安装后确认运行版本为 3.71.2.0，8 个程序文件校验一致，配置与配对保留并生成回退备份。排序交互证据来自隔离 WinForms 测试。
