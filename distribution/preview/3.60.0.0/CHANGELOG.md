# 努豆桌宠 3.60.0.0 预览版

- 专注与提醒分别打开；提醒继续独立计时。
- 专注页收窄，居中显示向上取整的剩余分钟；标题栏可设置本机字体和字号，剩余进度环随计时缩短。
- 可选择随专注播放自然环境声，默认关闭。仅由专注启动的环境声随暂停、继续及结束变化；手动播放不被专注接管，手动停止后本轮不自动恢复。
- 自然环境声面板使用五张场景图选景，预览双缓冲；手动动作、拖动优先，空闲20秒后恢复氛围动画。
- “时光小径”固定在脚边：暂停冻结并变淡，悬停显示精确剩余时间，点击打开专注；贴边显示小进度条。
- 正常专注结束后使用原生跳跃帧与像素撒花庆祝，可关闭或跳过；取消专注不庆祝，完成状态恢复不补播。
- 提醒协同方案仅记录，暂不实施；本轮不包含小鸭。

验证：423项静音自动断言；完整287帧图集、19种动作、4档缩放和16个视线方向自检通过；真实控件离屏预览已检查。

未测试：真实音频设备听感、实际桌面鼠标手势、多机/DPI硬件环境和本机安装重启。DPI布局通过模拟缩放检查。声音启停与优先级使用无设备的模拟后端验证。原生安装器未签名，保留 Windows 安全提示。
