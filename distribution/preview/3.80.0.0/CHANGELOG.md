# 努豆桌宠 3.80.0.0 Preview

## 新增与改进

- 每条便签可独立选择纸张颜色；快记设置可指定新便签默认颜色。修改默认色不会把已有便签统一改色。
- 折叠便签可拖出主窗口，成为独立桌面便签；也可从记录菜单打开。同一条便签使用同一记录标识，不会因为拖出而复制一份。支持多个独立窗口、各自置顶、Markdown 阅读、编辑、图片及字号调整。关闭主窗口不关闭独立便签，关闭便签只保存、不删除。
- 展开便签底部新增“发送到 Obsidian”。选择本机已有仓库后，主动发送 Markdown 和本地图片到仓库的“努豆快记”目录；原快记继续保留。
- 主窗口与独立窗口共享同一记录，未编辑的视图会刷新。两处同时修改时检查版本冲突，保留当前文字并阻止误覆盖；独立便签提供“备份当前并读取最新”，把本地修改备份后再载入另一窗口的更新。
- 保存失败时保留文字并阻止关闭。独立便签另存失败编辑恢复草稿，避免冲突内容因重新打开而被直接覆盖。

## 验证与使用

本版完成 341 项自动检查，覆盖颜色与默认设置、Obsidian 图文导出、独立窗口与并发编辑、原快记回归及安装器事务。验证使用隔离数据和原生窗口截图；不代表真实 Obsidian 仓库、物理设备或真人日常使用验收。

圆盘或右键菜单打开快记。按住折叠便签标题拖出主窗口即可放到桌面；独立便签使用自身的置顶开关。快记设置调整新便签默认颜色，每条记录旁的颜色入口只改变这一条。

发送到 Obsidian 是主动导出，不是持续双向同步。请先选择包含 `.obsidian` 文件夹的已有仓库，再点击发送。导出包含当前已保存的 Markdown 及其本地图片，原快记不会删除。

备份或迁移请保留 `nudou-quick-*.ini`、`quick-note-assets`、`quick-note-edit-drafts` 和 `quick-note-conflicts`。关闭前会确保写入完成；强制终止或突然断电时，尚未落盘的最后修改不保证恢复。安装更新沿用客户端原有确认流程。
