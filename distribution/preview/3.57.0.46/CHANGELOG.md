# 努豆桌宠 3.57.0.46 Preview

- 同一墨水屏任务反复完成、取消完成时，头顶气泡只显示最新收到的状态；不同任务分别显示。
- 离线补收合并展示；较旧记录晚到不会覆盖新状态。再次完成可产生新提醒，重复投递不会重复弹出。

- 保留应用内直接下载、校验、备份、更新和重启，以及 ToDo 的既有功能。

## 更新

3.57.0.45 及以后版本可在桌宠中点击“立即更新”。更早版本第一次请下载并运行 setup.exe，选择原安装目录；之后即可直接在桌宠内更新。

安装器保留设置、配对和任务记录，并创建回退备份。另提供纯解压 ZIP。程序包不含账号、配置、任务数据或源码。SHA256 见同目录校验文件。程序及安装器尚未代码签名，请遵循 Windows 安全提示。
