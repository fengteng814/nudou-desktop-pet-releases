# 努豆桌宠 3.69.0.0 Preview

相对上次公开版本 3.67.2.0 的累计更新：

- 新电脑可在桌宠内输入配对码连接任务服务，无需编辑配置文件；配对成功后自动加载清单。
- 配对码限时使用，支持断线后重试；连接信息加密保存在本机，已有电脑的配对保持不变。
- 家庭网络可直接连接指定 NAS；外网连接需先接入已授权的 Tailscale 网络。
- 管理清单先显示本地缓存，后台自动连接；ToDo 离线提示仅鼠标悬停时显示，保留搜索和未保存设置。
- 编辑待办时可以通过“保存到”转移清单，保留任务编号和完成状态；失败保留草稿。
- 修复檐下听雨抬臂时肩部衣料缺块，并改善亮色高光与蓝色衣料的过渡。

## 配对与适用范围

任务同步使用已部署的家庭任务服务。配对码由服务器管理员针对已授权的设备身份签发，有效期 10 分钟；不开放任意用户注册，也不自动扩大任务权限。请勿让两台正在使用的电脑共用一个身份。

## 下载与验证

推荐下载原生 EXE 安装包，核对版本后按安装器提示操作。便携 ZIP 用于解压运行。SHA256SUMS.txt 提供两份文件的校验值。

本版配对窗口与配置读写 36 项断言、服务端 9 项隔离测试（Windows 与 NAS Linux）、待办恢复 53 项与离线清单 48 项回归断言、应用自检以及安装器 21 项隔离检查通过。局域网及 Tailscale 地址上的配对兑换、加密保存、重新读取清单均已实际验证。

尚未在全新的 Windows 电脑上完成安装和人工输入配对码验收。本版仍为 Preview。VERSION.json 保留构建时元数据，当前发布状态以更新清单为准。
