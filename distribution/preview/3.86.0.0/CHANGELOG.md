# 努豆桌宠 3.86.0.0 Preview

## 新增与改进

- 颜色、更多与折叠操作固定在便签顶部，悬停时显示；折叠摘要与展开正文用动态过渡衔接。
- 优化输入时的重绘，中文输入法合成期间保留编辑状态与焦点。
- 修复阅读模式文字显示，长便签支持滚动阅读和编辑。
- Obsidian 选库改为弹出菜单，减少便签内部展开层级。

## 验证与使用

通过标题栏位置、悬停焦点、摘要渐隐与无动画路径、阅读文字与长文滚动、输入法合成消息、重复排版及选库菜单的隔离检查；回归新建排序、保存失败恢复、独立便签、冲突保护、图片与 Obsidian 导出，原生安装器隔离事务检查通过。

沿用原有便签数据、自动保存、颜色与 Obsidian 图文发送。更新保留设置和笔记，并提供原生安装备份。
