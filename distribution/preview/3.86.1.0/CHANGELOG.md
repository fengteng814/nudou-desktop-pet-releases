# 努豆桌宠 3.86.1.0 Preview

## 新增与改进

- 快记输入会话期间暂停自动字符格式改写，避免干扰拼音候选、编辑选区和背景绘制。
- 正文与选区读取改用不导出文本的原生接口，输入法组合结束后再通知自动保存。
- Markdown 排版在离开编辑后更新；保存、阅读模式和既有标题栏保持可用。

## 验证与使用

最终程序通过 241 项检查：输入会话与无副作用文本读取 33、标题栏及新建 65、功能回归 95、选库 16、实际微信输入法核验 11、原生安装器 21。实际微信输入法候选分别保持约 34 秒和 17 秒，空格选择得到中文，换行后继续输入成功；输入期间没有自动字符格式、选区改写、重绘开关或失焦消息。

更新保留便签、设置和原生安装备份。微信输入法已在隔离编辑器中完成真实键入、停顿选词和换行后再次选词验证。
