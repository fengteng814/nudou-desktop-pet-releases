# 努豆桌宠 3.84.0.0 Preview

## 新增与改进

- Todo 刷新主动请求同步，并在原通知区显示过程和结果；忙碌时保留一次后续请求。收起标签两侧留白更舒适。
- 修复玻璃效果下快记正文空白及标题图标黑色方块。文字仍直接输入、即时显示，不增加打字动画。
- 草稿和已存便签使用相同操作；颜色、更多和折叠按钮在每条右上角保持固定位置。展开直接显示可编辑正文。
- 每条便签可以直接选择预设颜色，新增醒目的 Obsidian 发送按钮；仓库选择默认收起。默认纸色仍在设置中调整。
- 拖动有跟手预览与插入位置反馈，拖出主窗口可成为独立便签，草稿同样支持。保留同一笔记标识、自动保存与窗口间同步。
- 加入已认可的十项动作：石头会动、困了还逞强、帅气落地、偷吃被发现、泡泡载人、口袋无底洞、披风大侠、背包太满、帐篷验收与窗口探头。保留完整结尾及原比例，播放完回到待机。
- 新动作默认相对权重为 6，原有权重、自主活动开关和设置保持。窗口探头需先在“生活日常 → 窗口探头”选择刚才的活动窗口，没有有效目标时不会随机触发。

## 验证与使用

最终程序通过快记界面、数据保存、Markdown、真实玻璃绘制及已认可动画回归，Todo 主动同步通过独立真实 HTTP 读取验证，安装器事务检查通过。具体证据与适用范围随本地验收记录保留。

使用独立笔记、模拟仓库和自建测试窗口验证；不以生产任务、笔记或 Obsidian 库作为测试数据。原生消息测试不等于真人中文输入法、真实多屏及长期体验验收。Markdown 编辑保留原文，完整图片与表格可在阅读视图查看。

窗口探头只读取明确选中窗口的位置和生命周期；关闭、隐藏、最小化或没有安全空间时退出，不读取窗口内容。窗口目标不持久化。

安装器仍保留“安装 / 更新”确认。普通关闭快记保留草稿，关闭独立便签不删除笔记。公开发布与本机是否已安装分别记录。
