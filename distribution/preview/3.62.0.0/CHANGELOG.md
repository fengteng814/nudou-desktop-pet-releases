# 努豆桌宠 3.62.0.0 Preview

- 保留玻璃模糊、强度及染色设置，修复自绘控件与原生输入控件的透明绘制链路；仅实际合成/绘制失败或高对比度模式进入标有“兼容显示”的回退。
- 开始专注后自动衔接环境场景；每轮随机场景保持稳定，尊重手动动作、拖动、音乐和静音优先级。
- 时间字体与圆环直径独立，暂停文字不再横穿圆环；齿轮改用矢量绘制，统一预设、自定义时长与开关对齐。
- 增加森林、海洋、暮色主题及状态配色；移除旧平面拖尾，增加宠物上方或下方的独立进度环，可调直径、粗细、间距与彗星效果。
- 713 项功能自动断言与程序自检通过；真实桌面 DWM 玻璃、实际鼠标操作、遮挡与跨显示器交互尚未验收。提醒协同未实现。

透明绘制证据来自隐藏窗口 WM_PAINT、ARGB/DIB 像素检测与离屏控件图；棋盘背景示意图不是实际桌面玻璃截图。原参考图未能通过官方下载流程成功落地，不能声称已与该图逐像素对照。
