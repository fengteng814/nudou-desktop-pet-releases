# 努豆桌宠 3.73.6.0 Preview

## 新增与改进

- 补齐多清单逐页读取异常诊断，记录具体页码、HTTP状态、异常类型及实际耗时，避免只剩汇总的 none/http0 而无法定位。
- 增加目录读取、页面时效和完整刷新耗时诊断。清单标识仅保存哈希与项目数字编号；不记录令牌、URL、任务标题、正文或异常消息。诊断写入失败不会阻断刷新。
- 保留新增任务置顶、已恢复任务及原审计记录；不改变任务状态、HTTP超时、页面时效判定、权限、系统时钟或网络配置。

## 使用范围与验证

诊断专项51项、原拒绝请求恢复54项、新增置顶112项、安装器21项及应用自检通过。覆盖页面503、格式异常、权限拒绝、第二页失败保留前页、7.2秒时差、超过10秒时差、过期和stale页面、诊断写入失败及敏感内容排除。

这是定位间歇读取失败的诊断更新，不表示网络稳定性问题已解决。原汇总 none/http0 表示快照不可用但没有附带异常，不能据此排除页面HTTP失败。页面未来时间或过期本身只改变提示和刷新间隔，不会独立触发不可用汇总。

安装后只需正常使用并采集诊断，不要重新恢复或创建已经成功的任务。保留现有配对和队列；本版与3.73.5队列格式兼容。现场持续运行仍待验收。

包内VERSION.json保留构建时状态，发布以更新源和发布页为准。
