# 努豆桌宠 3.57.0.6 Preview

新增约 8 秒的“灵感纸飞机 · 鼓棒指挥”动作，可从右键生活菜单执行；随机动作频率默认关闭，可在偏好设置中调整。动作支持暂停、恢复与现有倍率设置。

本版提供原生单文件安装器，以及解压后直接运行的 ZIP。安装器使用原生 Windows 界面，程序内更新仅安装经过严格校验的 v2 原生 EXE；保留现有配置、身份和数据，并建立可回退备份。更新前正常退出旧版，避免同时运行两份。

旧版 3.57.0.5 只接受 v1 ZIP 更新清单。若 preview 频道切换为 v2，它会拒绝该清单；请下载本版安装器手动升级。新版本可以读取旧 v1 清单，但不会执行旧 PowerShell 安装脚本。

安装器未做 Authenticode 签名。遵循 Windows 与组织的安全提示；受到阻止时停止操作。本版未宣称完成真实多屏、混合 DPI、家人或办公室电脑验收；NAS 与树莓派部署继续暂停。

源码仍私有。包内音频来源、许可记录和 CC0 文本保留；音频许可不授予图像或整个程序的许可。包内关于 private_candidate、published 的标记属于冻结构建时元数据，不能单独作为当前公开发行状态的证据。
