# 努豆桌宠 3.87.0.0 Preview

## 新增与改进

- 动作频率以可视化占比和交互控件调整，每个动画支持悬停预览。
- 独立便签标题栏不再重复显示首行，标题栏图标和发送区域悬停显示。
- 独立便签支持双击标题栏展开/收起、自由调整窗口大小、一键恢复默认大小。
- 独立与列表便签使用相同菜单，阅读背景融入便签窗口，空便签可正常保留。
- 修复玻璃效果下输入当前行背景闪烁和阅读文字消失，保留微信输入法编辑保护。
- 修复玻璃效果下独立便签边缘拖动不生效，窗口四边和角落可直接调整大小。

## 验证与使用

最终应用通过 627 项隔离自动检查，原生安装器通过 21 项，总计 648 项，覆盖动作占比与动画预览、空便签、输入会话、玻璃下输入和阅读、独立窗口与既有功能。最终应用另通过 6 项真实鼠标检查，确认玻璃下边缘缩放、恢复大小、双击收放和阅读显示。微信输入法的实际候选停顿、选词与换行验证保留原受测版本凭据；随后仅调整独立便签缩放，输入和阅读源码保持一致，该参考验证未计入 648 项。测试使用隔离目录，原有动画资源和用户笔记数据未被替换。

保留上一版输入会话保护、原有动画资源、笔记与设置。发布和本机安装分别依据实际凭据确认。
