# 努豆桌宠 3.77.0.1 Preview

## 新增与改进

- 鼠标进入 Todo 栏时，下方显示上次成功同步时间（精确到秒）和当前状态，停留期间随同步进度更新。
- 没有可靠记录时显示“暂无成功同步记录”；移出恢复简洁显示，离线与失败提示仍保留。
- 调整状态区高度，避免悬停时任务列表跳动，窄栏也能完整显示文字。
- 纳入缓存恢复改进：配置暂时不可读、授权失败或连接失败时保留已有任务；身份恢复后自动重新连接，后台刷新不阻塞本地缓存展示。
- 修正安装包版本元数据中的构建时间、基线版本和程序哈希。
