# 努豆桌宠 3.88.0.0 Preview

## 新增与改进

- 新增“平均分配”，将全部动作权重统一为 10；保存后生效，条件动作保持原触发条件。
- 动画预览使用透明背景并自动放大，支持调整大小和拖动位置。
- 快记与独立便签的图标补充悬停说明，阅读、编辑、置顶与折叠提示随当前状态更新。

## 验证与使用

最终应用通过 394 项针对性自动检查，原生安装器通过 21 项，共 415 项，覆盖平均分配、透明动画预览、按钮提示配置、既有标题栏和输入/阅读保护。最终应用另通过 4 项真实指针悬停检查，确认颜色、折叠、关闭及发送按钮的提示可见且控件焦点保持不变；这些实测不混入自动检查计数。动作资源和现代应用清单保持不变，测试使用隔离数据目录。

保留既有动画资源、笔记、设置和输入保护。发布与本机安装分别依据实际凭据确认。
