# 努豆桌宠 3.78.0.0 Preview

## 新增与改进

- 待办菜单及“同步状态”新增“诊断日志”，可一键复制，便于排查更新后同步内容为空的问题。
- 记录启动版本、最近启动历史、配置和缓存状态、连接错误代码、服务器返回的清单与任务数量、实际可见行数和完成项筛选。
- 日志不包含任务正文、密码、令牌或原始路径；复制不会发起同步或重发任务。近期日志按大小轮换，更新程序后继续保留。

## 验证与使用

17 项诊断检查、66 项缓存恢复回归检查和 21 项原生安装器事务检查通过。本机升级后配对文件不变，缓存保留，启动与缓存诊断记录已核验。单位电脑的空内容原因尚未确认；更新后出现问题时，请通过“待办菜单 → 诊断日志 → 复制诊断日志”提供排查信息。
