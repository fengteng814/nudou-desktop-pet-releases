# 努豆桌宠 3.66.0.0 Preview

相对上次公开版本 3.62.0.0 的累计更新：

- 新增全局外观入口：通透度、连续模糊、色调和主题配色实时同步至待办、圆盘和弹出面板；首次沿用待办已保存参数。
- 中键圆盘采用真实桌面玻璃效果，去除黑色底层，圆盘外围和分区间隙透明。
- 圆盘设置直接列出功能图标和名称，点击切换并自动保存，保留顺序调整和最多 12 项的限制；滚动条与待办统一。
- 新增自然环境氛围面板按钮；项目入口单独分区，默认折叠，不改变原有选择及顺序。

- 修复专注时中键、右键菜单弹出后立即关闭，以及小弧光绘制造成的异常；选择桌宠时保留当前模式。
- 完善专注、自然环境声和设置面板的玻璃效果；调整设置时，小弧光实时预览。
- 小弧光与大弧光一样按剩余时间倒退；悬停显示播放/暂停、静音、总时长和剩余时长，支持独立外观参数。
- 未悬停时，小弧光显示剩余分钟，文字外观可调；小弧光全部时间文字不显示秒，不足一分钟按一分钟显示。
- 恢复自然环境动画；静音只影响声音。专注面板数字下去掉“分钟”，休息说明支持独立参数。
- 修复“结束后跳跃撒花”文字遮挡，压缩底部空白，放大关闭按钮及设置文字，对齐预设和自定义时长。
- 开关靠右对齐，自然环境声齿轮放在右侧开关左侧，简化齿轮图标，删除每轮随机环境声下方小字。

## 下载与验证

本版使用本机已安装核验的同一份程序和安装包。安装包与便携包校验值见 SHA256SUMS.txt。
本版通过 85 项全局外观与圆盘专项检查、应用自检及 21 项安装器隔离检查；其余功能验证记录沿用此前候选版本，不计为本版重新执行。
原生窗口和受控桌面验证已执行；真实鼠标、多显示器和长时间使用仍需实际使用反馈。
VERSION.json 保留构建时元数据，公开发布状态以 Preview 更新清单为准。
