# 努豆桌宠 3.61.0.0 Preview

- 专注页失焦及打开环境声或其他桌宠菜单时保持显示；显式关闭、切页或退出仍可关闭，关闭视图不取消计时。
- 自然环境声、每轮随机环境声、结束庆祝采用 Switch；保存失败时回滚开关并显示原因。
- 随机环境声每轮选择一次可用场景，暂停、继续、刷新不重抽；保留手动声音优先级，不覆盖手动场景偏好。
- 数字始终居中；分钟与暂停分为两行。设置中可调整弧光直径、粗细、未开始/运行/暂停/完成颜色，以及彗星开关、亮度和彗尾。
- 统一时间数字、环境声场景与预览的背景；环境声和庆祝选项行取消独立底板；标题按钮无底板，圆角按钮保留实线键盘焦点提示。
- 调整预设和自定义分钟文字对齐，移除默认布局多余滚动条；环境声面板移除时长，新手动播放持续至明确停止，专注联动继续随本轮暂停/结束。
- 提醒继续独立计时；新的提醒协同方案仍仅设计，未实施。

验证：502 项自动断言、程序自检（19 动作、287 图格、4 档缩放、16 朝向）通过；真实 WinForms 控件离屏截图已检查。安装器沿用上版事务、备份与安全逻辑，单独执行隔离 fixture 验证。9 项发布记录测试通过。

待实测：真实鼠标点击、两个窗口同时打开的层级、实际 DWM 玻璃背景、音频设备听感及多屏/DPI 硬件环境。原 3.60 的“环境声勾不上”未在隔离控件测试中复现；本版替换点击绘制路径并补齐反馈，不能视为原机真实故障已完全闭环。DPI 仅通过控件缩放检查，声音优先级使用静音替身验证。预览视频由控件截图与图格合成，不是桌面录屏。

安装器与应用未签名；本次发布未在 Dell 自动安装、关闭或替换运行中的桌宠。升级保留已有配置；3.60.0.0 原公开安装器和解压包保留供回滚。
