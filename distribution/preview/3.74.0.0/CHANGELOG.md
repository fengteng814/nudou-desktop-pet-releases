# 努豆桌宠 3.74.0.0 Preview

## 新增与改进

- 新增「萤火晚灯」：努豆与三只萤火虫的十秒动作，保持桌面透明背景。
- 新增「回头补拍」：跳开、回头、跳回补敲鼓后回待机；采用已确认的去起点环与中心点版本。
- 两个动作位于右键 → 动作与娱乐 → 舞蹈与日常，保持人物原尺寸、面部、脚底定位和确认节奏。
- 保留 3.73.8 的待办刷新时效、规则读取状态、连接复用、新增任务置顶及原有配对、队列和功能。弹簧小鸭、园丁不加入，Heart 不修改。
