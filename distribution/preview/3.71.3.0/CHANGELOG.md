# 努豆桌宠 3.71.3.0 Preview

相对上次公开版本 **3.71.2.0** 的修复更新。

## 新增与改进

- 修复用户目录暂时不可用时可能形成相对配置路径、之后持续提示身份未确认的问题。每次重试重新解析目录，拒绝空路径和相对路径。
- 连接恢复后，已打开的待办和家庭留言窗口可以继续加载数据，保留正在输入的草稿。
- 增加脱敏的路径指纹和异常诊断，帮助区分配置缺失、访问失败、解密失败及网络问题，不记录凭据、原始路径或任务正文。
- 保留 3.71.2.0 的本机清单排序及此前功能，沿用现有配对和任务缓存。

## 使用范围与验证

身份与路径恢复 77 项检查通过，包含真实 WinForms 窗口恢复、草稿保留和离线缓存检查。清单后台同步 82 项、回执恢复 38 项回归通过；后两组在最终窗口绑定修复前运行，相关代码未变化。最终安装器 21 项隔离检查、应用自检及两次启动冒烟检查通过。

当前发布没有替换本机或单位电脑的已安装程序。单位电脑此前故障的旧进程缺少路径诊断，具体现场根因仍待新版运行观察；上述验证不代表单位电脑现场验收。

这是 Preview 版本。已有安装可通过桌宠“检查更新”获取，安装或更新由用户确认。便携包解压后运行。
