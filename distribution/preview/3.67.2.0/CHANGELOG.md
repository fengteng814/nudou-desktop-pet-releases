# 努豆桌宠 3.67.2.0 Preview

相对上次公开版本 3.66.0.0 的累计更新：

- 专注面板右侧新增近 7 天时长图表、完成比例和最近记录；本地保存历史，扣除暂停时间，旧历史不补造。
- 待办优先显示已验证身份下的本地缓存，再后台同步；配置短暂不可用、本地记录模块延迟启动时，可在原面板自动恢复。
- 离线显示缓存时间，授权失效单独提示；可选排序接口不可用不影响任务显示。
- 修正檐下听雨椅背上的旧胳膊轮廓，以及随抬臂移动的深色碎点。
- 改善中键圆盘高亮扇面的描边，分离玻璃底层与前景边缘的裁剪，并使用双倍采样平滑细线。

已知待完善：檐下听雨肩部高光与蓝色衣料在抬臂时的过渡，将在后续版本继续调整。
