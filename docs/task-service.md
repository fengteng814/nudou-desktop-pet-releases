# 任务服务配对

从 3.69.0.0 起，新电脑可以在桌宠窗口内完成配对，不需要编辑配置文件。

1. 向服务器管理员获取分配给这台电脑的配对码。
2. 打开“待办”，或者从右键设置分组进入“连接任务服务”。
3. 输入 12 位配对码，点击“连接”。连接成功后，桌宠会自动加载任务清单。

家庭网络使用默认连接方式。外网连接时，先接入能够访问任务服务器的 Tailscale 网络，再勾选“在外网连接”。

## 配对码和设备身份

配对码有效期为 10 分钟，只能由一台电脑兑换。同一电脑发生网络中断时，可在有效期内用原配对码重试；过期后请重新获取。

服务器只为已授权的设备身份签发配对码。增加新电脑身份需要管理员先授权，不开放任意账号自助注册。两台正在使用的电脑应使用各自的身份。

## 已有配对

升级会保留已有配对，不需要重新输入配对码。短暂离线时先检查网络并刷新待办；已有配置不会被配对窗口覆盖。

连接信息在本机加密保存。复制程序目录到另一台电脑不等于迁移设备授权。

## 常见提示

| 提示 | 下一步 |
| --- | --- |
| 配对码错误或已过期 | 核对输入，或向管理员重新获取 |
| 已被另一台电脑使用 | 获取分配给本机的新配对码 |
| 无法连接服务器 | 检查家庭网络或 Tailscale 连接 |
| 配对信息已收到，但任务服务尚不可用 | 待服务恢复后，用原配对码重试 |
| 本机已有任务服务配对 | 保留现有配置，检查原连接 |
