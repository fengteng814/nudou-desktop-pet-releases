# 仓库维护说明

本仓库为公开发行仓库。源码、服务器配置和开发测试材料保留在私有工作区。

## 目录与分支

| 位置 | 内容 |
| --- | --- |
| [Releases](https://github.com/fengteng814/nudou-desktop-pet-releases/releases) | 面向用户的版本页面和下载文件 |
| `README.md` | 当前版本与常用入口 |
| `docs/` | 安装、任务配对、历史版本和仓库说明 |
| `distribution/preview/<版本>/` | 已发布的固定版本安装包、说明和校验文件 |
| `support/` | 历史诊断材料，独立于桌宠安装包 |
| `updates` 分支 | 桌宠自动更新使用的渠道清单 |

## 发布约定

1. 为已验证的程序分配新版本，准备原生安装包、便携 ZIP、更新说明和 SHA256。
2. 将固定版本文件加入 `main`，通过匿名下载核对文件长度和哈希。
3. 更新 `updates` 分支的原生 Preview 清单，指向固定提交中的已验证安装包，再次回读确认。
4. 建立对应的 GitHub Preview Release，上传同一份文件；更新首页与历史索引。

已发布版本不得换内容后继续沿用同一版本号。目录整理使用普通提交，不重写历史、不搬走旧安装包，不修改旧版兼容更新清单。

`VERSION.json` 是构建时记录，保留当时的发布状态。当前公开状态以 GitHub 版本页面及更新渠道清单为准。
